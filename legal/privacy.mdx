# PRIVACY POLICY

**Effective Date:** February 07, 2026

At AzarineGuard, we prioritize the security of your scripts and the privacy of your data. This policy outlines how we handle information for both our **Customers (Developers)** and **End-Users (Players)**.

### 1. DATA COLLECTION: END-USERS

For users executing scripts protected by AzarineGuard, we collect specific identifiers to manage whitelisting and prevent unauthorized access.

**A. Data Shared ONLY with AzarineGuard (System Protected):**
The following data is used for security and anti-bypass measures. This data is **NOT** visible or accessible to the Developer/Script Owner:

* **IP Address:** Used to prevent multi-location login abuse and DDoS mitigation.
* **Hardware ID (HWID):** Used to bind licenses to specific devices.
* **Discord ID:** Used for internal authentication (unless you join the Developer's specific server).

**B. Data Shared with Script Developers:**

* **Timestamps:** Developers can see when their script was executed.
* **Discord ID:** Only if the user has joined the Developer's Discord server and authorized the integration.

**C. What We DO NOT Collect:**
AzarineGuard is designed to be privacy-friendly. We do **NOT** log or store:

* Roblox Usernames or User IDs.
* In-game statistics, inventories, or chat logs.
* Device names or sensitive personal files.

---

### 2. DATA COLLECTION: DEVELOPERS

For Developers purchasing and using the AzarineGuard dashboard, we collect:

* **Account Identifiers:** Discord ID and IP Address for account security.
* **Provided Data:** Any information explicitly entered through the AzarineGuard dashboard (e.g., script names, version notes).
* **Authentication Data:** We use cookies solely for maintaining your login session. By using our dashboard, you consent to these functional, non-sensitive cookies.

---

### 3. SCRIPT SECURITY & STORAGE

We understand the value of your Intellectual Property (IP).

* **Raw Script Handling:** When you upload a Lua script for protection, the raw source code is processed and obfuscated immediately.
* **Automatic Deletion:** Once obfuscation is complete, the **raw source code is permanently deleted** from our active processing cache.
* **Storage:** We only store the final obfuscated/encrypted version of the script required for your users to execute the service.

---

### 4. DATA RETENTION & SECURITY

* **Retention:** We retain data only as long as your account is active or as needed to provide whitelisting services.
* **Security:** We implement industry-standard encryption to protect against unauthorized access, alteration, or destruction of data.
* **Third-Party Disclosure:** We do not sell, trade, or otherwise transfer your data to outside parties. This does not include trusted third parties who assist us in operating our website (e.g., hosting providers) so long as those parties agree to keep this information confidential.

---

### 5. COOKIE CONSENT

AzarineGuard uses "Strictly Necessary" cookies. These are essential for you to browse the website and use its features, such as accessing secure areas of the site. Because these cookies are strictly for authentication and security, they are active by default upon using the service.

---

### 6. CONTACT US

If you have questions regarding this Privacy Policy, you may contact us via our official Discord Support Server.
